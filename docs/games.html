Game Launcher Detector

A single batch file that detects every game on your Windows machine — Steam library, Roblox player, Minecraft install, Epic Games launcher — and shows you how to combine them into an e# playable game.

Supported launchers

Steam

Reads steamapps/libraryfolders.vdf and lists every installed game.

Roblox

Detects RobloxPlayerBeta.exe in %LOCALAPPDATA% and reports the version.

Minecraft

Finds .minecraft/launcher_profiles.json and counts the profiles.

Epic Games

Reads Epic's LauncherData.dat and lists the installed titles.

Run it

Download game-launcher-detector.bat, double-click it, and the batch file writes a games.json file you can pass to e#.

Download game-launcher-detector.bat hello.esharp

What the batch file does

When you double-click game-launcher-detector.bat, it runs in three phases:

Phase 1 — Detect Steam
  → Read %PROGRAMFILES(X86)%\Steam\steamapps\libraryfolders.vdf
  → Parse every steamapps/manifest_*.acf file
  → Output: Steam games list + install paths

Phase 2 — Detect Roblox & Minecraft
  → %LOCALAPPDATA%\Roblox\Versions\RobloxPlayerBeta.exe   ← Roblox installed?
  → %APPDATA%\.minecraft\launcher_profiles.json            ← Minecraft installed?
  → Output: Roblox version, Minecraft profiles

Phase 3 — Detect Epic Games
  → %PROGRAMFILES(X86)%\Epic Games\Launcher\Data\Manifests\*.item
  → Output: Epic installed titles

Phase 4 — Write games.json
  → Write a JSON manifest of every detected game to .\games.json
  → Print a copy-paste e# snippet that uses Steam::library().pick(title)

        Scene::from(Steam::library().pick("Portal 2")),

Combining games & running the test

Once you have games.json, write your .esharp program that picks games by title, then build + run:

# Build the .game bundle
esharp build mashup.esharp

# Run it to test
esharp run mashup.game

# If everything works, you'll see:
✓ Build OK
✓ Runtime launched · 60 fps · 0 errors
✓ Scenes registered: Portal 2, Stardew Valley, Hollow Knight

No administrator rights needed

The detector batch file does not require admin elevation. It only reads files in user-writable locations: %LOCALAPPDATA%, %APPDATA%, and the user's Steam directory. It does not modify any files.
