What the Cloud Console shows

The Cloud Console is a unified dashboard for every API Board key in your account. Each key is identified by:

  • Service — which API on the board this key calls (Movie, Weather, Tracking, …)
  • Environment — production, staging, or sandbox.
  • Editor — the code editor you used to create the key (Visual Studio 2022, VS Code, Cursor, WebStorm, Rider, Neovim, or Other).
  • Purpose — a free-form string describing what you'll use the key for.
  • Status — active, rotating, paused, or revoked.
  • Quota — calls today / quota per day, color-coded by % used (green < 70%, amber 70–90%, red > 90%).
  • Sparkline — daily call count for the last 14 days.

Actions

From the console you can:

  • Create a key — pick service, environment, editor, purpose, and key prefix.
  • Reveal / Copy — toggle visibility on the masked key, then copy it.
  • Rotate — generates a new key; the old one stays valid for 7 days for zero-downtime deploys.
  • Pause / Resume — temporarily stop traffic to a key without revoking it.
  • Revoke — permanently disable a key.

Live activity feed

The right pane of the console shows every API call, key rotation, quota warning, and webhook delivery in real time. Each event has a timestamp, service, status code, and latency. Click any event to see the full request + response payload.
