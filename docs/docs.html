Quickstart

# 1. Clone the repo
git clone https://github.com/gefrus112/API-board.git
cd API-board

# 2. Install dependencies
npm install

# 3. Start the dev server
npm run dev

# 4. Open the app
open http://localhost:3000

Windows installers

Run as administrator (where indicated):

# Install the API Board Connect extension into VS 2022
install-apiboard-vs.bat   # admin

# Install the e# language toolchain
install-esharp.bat        # admin

# Drop style.css into any project root
connect-style-sheets.bat  # no admin

# Detect installed Steam, Roblox, Minecraft, Epic games
game-launcher-detector.bat  # no admin

Make your first API call

curl -X GET \\
  'https://api.apiboard.dev/v1/weather/forecast?city=Berlin&units=metric' \\
  -H 'Authorization: Bearer ab_live_weather_4e2f9a8c1d6b3f7e'

# Response (200):
{
  "location": { "name": "Berlin", "country": "DE" },
  "current": { "temp_c": 14.2, "condition": "Partly cloudy" },
  "forecast": [{ "date": "2026-10-15", "high_c": 16, "low_c": 8 }]
}
