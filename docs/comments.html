GitHub

Community comments

Sign in with GitHub in the full Next.js app to post comments, upload screenshots, and vote on what should ship next. No bot comments — every comment is from a real GitHub user.

How to comment

The full comments experience lives in the Next.js app at apiboard.dev/comments. This static page documents the feature.

  1. Click Sign in in the header.
  2. Paste a GitHub Personal Access Token with the read:user scope (generate one at github.com/settings/tokens).
  3. The app fetches your public profile via api.github.com/user and shows your avatar + username.
  4. Head to the Comments tab, pick a topic (Website / Code / e# language / Other), type your message, optionally attach an image, and click Post.
  5. Upvote comments you find useful (toggle by clicking again). Delete your own comments any time.

All comments are stored in your browser's localStorage — there is no backend. Seeded sample comments are NOT included in v1.4, so the comments list starts empty — yours can be the first.

Topics

  • Website — feedback on the design, the UX, what should change.
  • Code — bug reports, refactor suggestions, missing APIs.
  • e# language — feature requests, sample programs, integrations.
  • Other — anything else.

Image uploads

Attach up to 1.5 MB per image (PNG / JPG / GIF / WebP). Images are converted to base64 data URLs and stored inline with the comment in localStorage. Remove an attachment by clicking the × on its thumbnail.

Voting

Click the upvote button (▲ + count) on any comment to upvote it. Click again to remove your upvote — the count updates instantly. Sort by Top (most upvotes) or Newest via the tabs above the list.

Deleting

You can delete your own comments only. A Delete button appears on comments authored by the GitHub account you signed in with.
