Meet e# (esharp)

A Rust-inspired programming language that combines your Steam games together into one playable experience.

use api_board::{Steam, Weather};

game! SteamMashup {
    title: "Open-world crossover",
    scenes: [
        Scene::from(Steam::library().pick("Portal 2")),
        Scene::from(Steam::library().pick("Stardew Valley")),
    ],
}

fn main() -> Game {
    let mut game = SteamMashup::new();
    game.play()
}

Game Launcher Detector

A single batch file that detects every game on your machine — Steam library, Roblox player, Minecraft install, Epic Games launcher — and shows you how to combine them into an e# game.

Steam

Reads steamapps/libraryfolders.vdf and lists every installed game.

Roblox

Detects RobloxPlayerBeta.exe in %LOCALAPPDATA% and reports the version.

Minecraft

Finds .minecraft/launcher_profiles.json and counts the profiles.

Epic Games

Reads Epic's LauncherData.dat and lists the installed titles.
